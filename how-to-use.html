How to use HANKO: Client Approvals

From installation to your first approved item in about five minutes.

Prerequisites

  • A monday.com account. Installing the app requires an account admin.
  • A board with an item you want approved and a Status column that will show the result.
  • Optional: a Files column with the deliverables you want your client to see.

1. Install the app

Open the monday.com marketplace, find HANKO: Client Approvals, and click Add to your account. Approve the permissions it requests: read and write board data (to read the item and update its status) and post updates.

2. Add the view to a board

Open your board, click + next to the existing views, and add Client approvals. The view lists every request created on this board and shows how many of your monthly free requests you have used.

3. Configure the result (first time only)

Open Settings in the view and choose:

  • Status column to update when your client responds.
  • Labels for approved and changes requested. They must match the labels in your column exactly.
  • Brand name and accent color shown on the client page.
  • Default link expiry in days.
If no status column is configured, responses are still saved but the board cannot be updated, and the app tells you that setup is needed.

4. Create an approval request

Click New request. Choose the item, enter a name for the recipient (for example the client's company), add an optional message, tick the files to include, and set the expiry.

5. Share the link

Copy the generated link and send it to your client yourself, for example by email or chat. The app does not send emails.

Anyone who has the link can answer, so ask your client not to forward it.

6. Your client responds

The client opens the link on any device, with no sign-in. They review your message and files, then choose Approve or Request changes. Requesting changes requires a comment. A request can be answered once. If changes are needed, create a new request after updating the work.

7. See the result on your board

The status column changes to your chosen label, and an update is added to the item, for example "Approved by Acme Coffee (via shared link)". For changes requested, the client's comment is included. Use the normal monday.com notifications to be alerted.

Managing requests

  • Copy link again or Withdraw a request from the view while it is waiting. A withdrawn or expired link shows no content.
  • Changes requested comments are visible in the request list.

Plans and limits

  • Free: up to 10 new requests per month. When the limit is reached, creating new requests is paused; links you already issued keep working.
  • Paid: unlimited requests.
  • Cancelling a paid plan stops paid features but keeps your saved data.

Uninstalling

When an account admin uninstalls the app, all requests, settings and the stored authorization for that account are deleted, and previously issued links stop working.
